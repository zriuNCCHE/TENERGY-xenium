# Major Cell Type Palette

This final Figure 2 helper part stores the shared color palette for broad UMAP and H&E/spatial overlays.

Major groups:

- `A2ML1+ epithelial cells`
- `fibroblast & endothelial cells`
- `immune cells`
- `malignant cells`

Outputs:

- `outputs/figure2_major_cell_type_palette.pdf`: visual palette panel.
- `outputs/figure2_major_cell_type_palette.csv`: palette table for server-side plotting.
