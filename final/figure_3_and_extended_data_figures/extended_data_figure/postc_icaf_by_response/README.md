# PostC iCAF Proportion By Response

This final Extended Figure 4 part compares postC iCAF subtype proportions among fibro-immune cells between cCR and non-cCR samples.

Denominator:

- Fibro-immune cells in each sample, defined as all cells except `A2ML1+ epi` and `malignant`.

Plotted subsets:

- `iCAF_CXCL5`
- `iCAF_CXCL6`

Outputs:

- `outputs/postc_icaf_by_response_summary.csv`: sample-level percentages.
- `outputs/postc_icaf_by_response_unadjusted_stats.csv`: unadjusted Wilcoxon rank-sum tests.
- `outputs/postc_icaf_by_response.pdf`: vector figure.
