# Fibro-Immune Stromal Proportion

This final Figure 4 part plots selected fibroblast/endothelial subset proportions among fibro-immune cells across treatment timepoints.

Denominator:

- Fibro-immune cells in each sample, defined as all cells except `A2ML1+ epi` and `malignant`.

Plotted subsets:

- `myCAF_MMP11`
- `myCAF_TNFRSF21`
- `iCAF_CXCL5`
- `iCAF_CXCL6`
- `endo_PLVAP`
- `vCAF`

Outputs:

- `outputs/fibro_immune_stromal_proportion_summary.csv`: sample-level percentages.
- `outputs/fibro_immune_stromal_proportion_unadjusted_stats.csv`: unadjusted paired Wilcoxon tests.
- `outputs/fibro_immune_stromal_proportion.pdf`: vector figure.
