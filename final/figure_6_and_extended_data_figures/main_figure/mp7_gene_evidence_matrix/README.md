# MP7 Gene Evidence Matrix

Final Figure 6C candidate.

This part shows selected MP7 genes ordered by biological feature group and summarizes their evidence in two DEG contrasts:

- pretreatment non-cCR malignant cells versus cCR malignant cells
- postC non-cCR malignant cells versus pretreatment non-cCR malignant cells

Genes are grouped as laminin-332, adhesion/anchoring, remodeling/invasion, and broader stress/adaptation features.

## Files

- `code/plot_mp7_gene_evidence_matrix.R`: copied from the exploratory metaprogram-DEG overlap analysis script used to generate the matrix.
- `outputs/figure_6c_mp7_gene_evidence_matrix.pdf`: final Figure 6C candidate panel.
- `results/mp7_matrix_remodeling_gene_evidence.csv`: MP7 gene-level DEG evidence table.
- `results/shared_pre_nonccr_postc_metaprogram_genes.csv`: shared metaprogram genes higher in pretreatment non-cCR and postC non-cCR.
