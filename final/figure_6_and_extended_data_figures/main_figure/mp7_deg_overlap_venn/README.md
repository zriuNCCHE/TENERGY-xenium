# MP7 DEG Overlap Venn

Candidate Figure 6B.

This part shows a focused three-set Venn summary:

- MP7 basal/invasive matrix-remodeling genes.
- Genes higher in pretreatment non-cCR malignant cells versus cCR.
- Genes higher in postC non-cCR malignant cells versus pretreatment non-cCR.

The Venn areas are intentionally not proportional so the small MP7 set remains legible.

## Files

- `code/plot_mp7_deg_overlap_venn.R`: final Venn plotting script.
- `outputs/figure_6b_mp7_deg_overlap_venn.pdf`: candidate Figure 6B panel.
- `results/mp7_deg_overlap_venn_counts.csv`: Venn region counts and genes.
- `results/mp7_deg_overlap_venn_shared_groups.csv`: shared MP7 genes grouped by biological feature.
