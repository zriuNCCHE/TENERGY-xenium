Figure 6 top-50 DEG overlap legend draft

Top-50 DEG overlap between malignant-cell metaprograms and DEG lists. Top genes were selected separately from pretreatment non-cCR-enriched genes and non-cCR post-chemoradiotherapy-enriched genes by positive Scanpy rank_genes_groups score in the indicated direction. Numbers indicate genes shared between each metaprogram gene set and the indicated top-50 DEG list.

The shared-both-top-50 column counts metaprogram genes present in both the pretreatment non-cCR top-50 list and the non-cCR postC top-50 list.

This top-50 analysis is a compact reference version. The primary all-significant-DEG overlap uses adjusted P < 0.05 and log2 fold change >= 0.25; exact gene-level log2 fold changes and adjusted P values are saved in `../metaprogram_deg_overlap/results/metaprogram_deg_gene_evidence.csv`.
