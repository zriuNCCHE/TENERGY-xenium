# Metaprogram DEG overlap numbers

(C) Heatmap summarizing the number of genes from each malignant-cell metaprogram that overlap pretreatment non-cCR-high DEGs, non-cCR post-chemoradiotherapy-high DEGs, or both. DEGs were defined using adjusted P < 0.05 and log2 fold change >= 0.25 in the indicated direction. MP7 had the strongest shared overlap across the two resistance-associated contrasts. Exact gene-level log2 fold changes and adjusted P values are saved in `results/metaprogram_deg_gene_evidence.csv`.
