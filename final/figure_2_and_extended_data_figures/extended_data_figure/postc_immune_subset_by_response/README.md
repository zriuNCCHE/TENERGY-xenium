# PostC Immune Subset Proportion By Response

This final Extended Figure 3 part compares postC proportions of selected immune subsets among fibro-immune cells between cCR and non-cCR samples.

Denominator:

- Fibro-immune cells in each sample, defined as all cells except `A2ML1+ epi` and `malignant`.

Plotted subsets:

- `Macro_CXCL5`
- `Mono_CDC27`
- `Mono_SLC2A3`
- `Neutrophil`

Outputs:

- `outputs/postc_immune_subset_by_response_summary.csv`: sample-level subset percentages among fibro-immune cells.
- `outputs/postc_immune_subset_by_response_unadjusted_stats.csv`: unadjusted Wilcoxon rank-sum tests.
- `outputs/postc_immune_subset_by_response.pdf`: vector figure.
